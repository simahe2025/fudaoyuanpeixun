# 辅导员培训班网站

智慧党建引领 网络思政赋能 - 辅导员队伍赋能提升培训班官方网站

## 项目简介

本项目是广东第二师范学院辅导员培训班的官方展示网站，展示培训活动的精彩内容、学员风采和培训成果。

## 功能特色

- 📱 响应式设计，支持多设备访问
- 🎨 现代化UI界面，用户体验出色
- 📊 多标签页展示不同内容模块
- 🖼️ 图片集锦展示培训精彩瞬间
- 📝 详细的培训课程安排和简报
- 👥 小组风采展示

## 技术栈

- HTML5
- CSS3 (Grid布局、Flexbox、动画效果)
- JavaScript (ES6+)
- Font Awesome 图标库
- Google Fonts 字体

## 项目结构

```
├── index.html          # 主页面
├── css/
│   ├── main.css        # 主样式文件
│   ├── responsive.css  # 响应式样式
│   └── animations.css  # 动画效果
├── js/
│   ├── main.js         # 主脚本文件
│   ├── tabs.js         # 标签切换功能
│   └── utils.js        # 工具函数
├── images/             # 图片资源
├── assets/             # 其他静态资源
└── docs/               # 文档目录
```

